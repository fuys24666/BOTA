# Ali Stage 0 Amendment 04

This amendment freezes Stage 5 before any sequential result is generated. It
does not modify the original preregistration or the completed Stage 1--4A
interpretations.

The primary experiment uses the registered L4M4 users under low-first,
middle-first, alternating and deterministic-hash order. Cumulative request
sizes are 1, 2, 4 and 8 for seeds 41, 42 and 43. L8 is retained as a
deterministic-hash low-frequency robustness sequence. Every cumulative endpoint
is recomposed from the same canonical 200-step endpoint; blind chaining from a
previously published Adapter is not the primary algorithm.

Each unique cumulative user union is paired with a fresh 200-step Exact-Masked
replay using the unchanged ordered schedule and full batch denominator. All 60
seed-order-size cells are reported. Stage 5 MIA output is descriptive because
the frozen Stage 4 and Stage 4A reference-signal gates failed.

The primary K=2 decision requires every L4M4 order-family mean residual to be
below one, a maximum-minus-minimum order spread no greater than 0.10, and all
twelve seed-order cells to satisfy the existing utility guardrails. Failure
retains one-shot-only scope.
